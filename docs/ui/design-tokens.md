# Design tokens

## Color

- Canvas: `#f5f7f6`
- Surface: `#ffffff`
- Ink: `#17231f`
- Muted ink: `#68756f`
- Border: `#e3e9e6`
- Brand: `#176b4d`
- Brand dark: `#0e4d37`
- Navigation: `#11231d`

Semantic success, warning, error, and informational colors must pass WCAG AA
contrast in their final component context.

## Shape and spacing

The base spacing increment is 4px. Operational cards use a 14px radius;
controls use 8–10px. Shadows remain subtle so hierarchy does not depend on
decoration.

## Typography

Geist Sans is the primary UI family and Geist Mono is reserved for identifiers,
references, timestamps, and keyboard shortcuts. Arabic typography will be
selected and tested with the Phase 3 localization shell.
