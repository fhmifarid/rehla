# Screen patterns

List screens provide search, filters, sorting, cursor pagination, saved views,
column visibility, date ranges, exports, refresh, bulk selection, and safe bulk
actions where meaningful. State is encoded in the URL.

Detail screens combine immutable identifiers, current status, primary actions,
summary, related resources, activity timeline, and audit access. Financial
screens separate pending, posted, reversed, and failed records and never offer
hard deletion.

Forms use UI feedback for usability, but API DTO validation, domain policies,
and database constraints remain authoritative.
