# Project overview

Rehla is a bilingual travel commerce and operations platform. The primary
initial products are a Go backend and Next.js administration application; a
Flutter customer application will consume the same versioned API later.

The platform is greenfield. It intentionally has no Firebase compatibility,
legacy API compatibility, Khalti integration, or migration layer.

## Product boundary

The target includes catalog, departures and inventory, orders, travelers,
manual bank transfers, reconciliation, wallet, refunds, double-entry ledger,
support, CMS, growth, partners, analytics, automation, RBAC, approvals, audit,
risk, and settings.

## Current milestone

Phase 1 foundation is implemented. Phase 2 identity and security is next.
